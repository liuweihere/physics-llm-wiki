这里仅接收从 `../feynman-physics-wiki/` 整理并适合公开展示的内容。当前目录先保留静态内容与前端代码的边界，后续可以接入 Vite + Vue、Vite + React、Astro，或继续使用纯 Markdown 静态站点。

- [`content/stages/`](content/stages/)：按年龄阶段整理的讲次。
- [`content/main-lines/`](content/main-lines/)：四根核心主线。
