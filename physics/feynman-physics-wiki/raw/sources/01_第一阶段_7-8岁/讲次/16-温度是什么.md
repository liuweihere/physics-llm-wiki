# 第16讲：温度是什么？——平均激烈的程度

| 项目 | 内容 |
|------|------|
| **课程标题** | 温度是什么？——平均激烈的程度 |
| **对应主线** | 物质的微观建筑 + 能量与账本 |
| **核心问题** | 温度计上的数字到底在量什么？ |
| **自制 Notebook 视频** | 16–20分钟。用费曼口吻把“温度 = 分子平均动能”讲清楚，用生活例子。 |
| **外部视频参考** | 1. Feynman「Heat is jiggling」完整片段<br>2. 短视频「温度与分子速度」动画 |
| **交互模拟器** | PhET「Gas Properties」（可加热气体看分子速度变化） |
| **阅读材料 / 书籍** | 《能量无处不在》；《这就是物理》热学分册 |
| **动手实验** | 1. 用手感受热水、温水、冷水的差异<br>2. 用温度计量不同水温，同时观察扩散速度 |
| **直觉量化点** | 温度越高 → 分子平均跳得越快 → 扩散越快、碰撞越猛 |
| **留下的钩子** | 有没有一个温度，让所有分子都彻底停下来？ |
| **知识地图节点** | 物质微观建筑 · 第3次回旋 |
