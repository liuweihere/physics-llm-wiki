# 第1讲：坐在高铁上，为什么树在后退？

| 项目 | 内容 |
|------|------|
| **课程标题** | 坐在高铁上，为什么树在后退？ |
| **对应主线** | 运动与时空 |
| **核心问题** | 树真的在动吗？还是我们在动？如果高铁突然停下来，树会怎样？ |
| **自制 Notebook 视频** | 15–18分钟。用费曼口吻讲述参照系，配高铁/玩具车实拍或动画。结尾抛出“向上抛球会怎样”的钩子。 |
| **外部视频参考** | 1. Feynman《Fun to Imagine》相关片段（相对运动直觉）<br>2. Khan Academy - Reference frames（中文字幕版） |
| **交互模拟器** | PhET「The Moving Man」（可调节速度、观察位置-时间图） |
| **阅读材料 / 书籍** | 《费曼讲物理：入门》相关运动描述；《这就是物理》运动分册对应页 |
| **动手实验** | 1. 坐在滑板/椅子上被推动，观察墙上的画<br>2. 站在地上看玩具车开过<br>材料：滑板或椅子、玩具车、一张画 |
| **直觉量化点** | 同样速度，离我们近的东西看起来“跑”得更快 |
| **留下的钩子** | 如果在开动的火车里向上抛球，球会落在后面吗？ |
| **知识地图节点** | 运动与时空 · 第1次回旋 |
