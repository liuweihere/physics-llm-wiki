# 第18讲：为什么冰会浮在水上？

| 项目 | 内容 |
|------|------|
| **课程标题** | 为什么冰会浮在水上？ |
| **对应主线** | 物质的微观建筑 |
| **核心问题** | 大多数固体沉在液体里，为什么冰却浮在水上？ |
| **自制 Notebook 视频** | 16–20分钟。用费曼口吻从密度进入，讲水结冰时分子排列变得更“空”。 |
| **外部视频参考** | 1. 水结冰密度变化动画<br>2. 短视频「冰为什么浮在水上」 |
| **交互模拟器** | PhET「States of Matter: Basics」 |
| **阅读材料 / 书籍** | 《这就是物理》；《能量无处不在》 |
| **动手实验** | 1. 观察冰块在水中的漂浮<br>2. 对比其他固体（石头、木头）在水中的情况<br>材料：冰块、透明杯子、清水 |
| **直觉量化点** | 冰的密度比水小，所以浮起来；这是水的特殊分子结构导致的 |
| **留下的钩子** | 水分子如何“逃跑”变成水蒸气？又如何“回家”变成水？ |
| **知识地图节点** | 物质微观建筑 · 第5次回旋 |
