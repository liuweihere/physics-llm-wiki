# 第26讲：综合回旋——用四根主线解释“一次完整的飞行”

| 项目 | 内容 |
|------|------|
| **课程标题** | 综合回旋：用四根主线解释“一次完整的飞行” |
| **对应主线** | 四根主线全部回旋 |
| **核心问题** | 从起飞到落地，飞机到底经历了什么？我们能不能用四根主线把它讲清楚？ |
| **自制 Notebook 视频** | 20–25分钟。这是第一阶段的收官之作。用费曼口吻带着孩子把运动与时空、相互作用与场、能量与账本、物质微观建筑全部串起来，完整讲述一次飞行。 |
| **外部视频参考** | 1. 真实飞机起飞落地纪录片片段<br>2. 之前各讲的自制视频回顾 |
| **交互模拟器** | 综合回顾 PhET「Buoyancy」「Projectile Motion」「Energy Forms and Changes」「Gravity and Orbits」 |
| **阅读材料 / 书籍** | 回顾《费曼讲物理：入门》+《这就是物理》相关章节 |
| **动手实验** | 1. 折一架纸飞机，完整体验“起飞—飞行—落地”<br>2. 用四根主线的语言，让孩子自己讲述刚才的飞行过程 |
| **直觉量化点** | 一次完整的飞行需要：参照系与运动描述、升力与阻力（场与力）、能量转化（化学能→动能→热能）、空气分子的碰撞与压强 |
| **留下的钩子** | 第一阶段结束。下一阶段（9–10岁）我们将带着更锋利的工具，再次回到这些主线，看得更深。 |
| **知识地图节点** | 四根主线全部完成本阶段回旋，第一阶段（7–8岁）正式收官 |
