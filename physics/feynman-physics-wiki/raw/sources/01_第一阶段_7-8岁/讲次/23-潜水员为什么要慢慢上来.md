# 第23讲：潜水员为什么要慢慢上来？

| 项目 | 内容 |
|------|------|
| **课程标题** | 潜水员为什么要慢慢上来？ |
| **对应主线** | 相互作用与场 + 物质的微观建筑 |
| **核心问题** | 水越深压强越大吗？突然上来会发生什么？ |
| **自制 Notebook 视频** | 16–20分钟。用费曼口吻从压强随深度增加进入，讲减压病的直觉原因。 |
| **外部视频参考** | 1. 潜水减压病科普短片<br>2. 水下压强演示实验视频 |
| **交互模拟器** | PhET「Under Pressure」（可观察液体压强随深度变化） |
| **阅读材料 / 书籍** | 《这就是物理》；《能量无处不在》相关页 |
| **动手实验** | 1. 用塑料瓶在不同深度挤扁，感受压强差异<br>2. 在透明桶里用吸管或软管感受深度压力<br>材料：塑料瓶、透明水桶、清水 |
| **直觉量化点** | 深度增加一倍，水的压强大约增加一倍 |
| **留下的钩子** | 飞机翅膀为什么能飞？是不是也和压强有关？ |
| **知识地图节点** | 相互作用与场 · 第10次回旋 |
