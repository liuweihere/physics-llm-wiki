# 第8讲：正负电荷的“喜欢”与“讨厌”

| 项目 | 内容 |
|------|------|
| **课程标题** | 正负电荷的“喜欢”与“讨厌” |
| **对应主线** | 相互作用与场 |
| **核心问题** | 如果有两种电荷，它们会怎样相处？ |
| **自制 Notebook 视频** | 15–20分钟。用费曼口吻讲同性相斥、异性相吸，建立“两种电荷”的清晰图像。 |
| **外部视频参考** | 1. PhET「Balloons and Static Electricity」进阶玩法<br>2. 短视频「两根气球互相排斥」实验 |
| **交互模拟器** | PhET「Balloons and Static Electricity」+「John Travoltage」 |
| **阅读材料 / 书籍** | 《这就是物理》；《Feel the Force》电磁相关 |
| **动手实验** | 1. 两根同样摩擦过的气球互相靠近（排斥）<br>2. 一根摩擦过的气球靠近没摩擦的墙（吸引） |
| **直觉量化点** | 距离越近，排斥或吸引的感觉越强 |
| **留下的钩子** | 冬天脱毛衣为什么会“噼啪”响？那些小火花是什么？ |
| **知识地图节点** | 相互作用与场 · 第2次回旋 |
