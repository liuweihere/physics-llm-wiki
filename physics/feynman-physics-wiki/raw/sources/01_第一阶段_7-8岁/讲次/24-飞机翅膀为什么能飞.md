# 第24讲：飞机翅膀为什么能飞？

| 项目 | 内容 |
|------|------|
| **课程标题** | 飞机翅膀为什么能飞？ |
| **对应主线** | 相互作用与场 + 运动与时空 |
| **核心问题** | 飞机那么重，怎么能飞上天？翅膀上下有什么不同？ |
| **自制 Notebook 视频** | 18–22分钟。用费曼口吻从伯努利原理的直觉进入（不讲公式），强调上下压力差。 |
| **外部视频参考** | 1. 纸飞机与机翼原理动画<br>2. Crunch Labs 或类似飞行实验 |
| **交互模拟器** | PhET 暂无完美对应，可用「Fluid Pressure and Flow」辅助理解 |
| **阅读材料 / 书籍** | 《这就是物理》；《Feel the Force》 |
| **动手实验** | 1. 对着纸条上方吹气，观察纸条升起<br>2. 折纸飞机，对比不同翼型的飞行效果<br>材料：A4纸、剪刀 |
| **直觉量化点** | 空气流过上表面路径更长 → 速度更快 → 压强更小 → 产生升力 |
| **留下的钩子** | 连通器与喷泉——水为什么有时候会自己往高处跑？ |
| **知识地图节点** | 相互作用与场 · 第11次回旋；运动与时空 · 第7次回旋 |
