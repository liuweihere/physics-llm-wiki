# 第21讲：为什么大船能浮在水面上？

| 项目 | 内容 |
|------|------|
| **课程标题** | 为什么大船能浮在水面上？ |
| **对应主线** | 相互作用与场 + 物质的微观建筑 |
| **核心问题** | 铁做的大船明明比水重，为什么不会沉？ |
| **自制 Notebook 视频** | 16–20分钟。用费曼口吻从阿基米德的故事进入，建立“浮力 = 排开的水的重量”的直觉。 |
| **外部视频参考** | 1. PhET「Buoyancy」官方演示<br>2. 短视频「阿基米德原理」动画 |
| **交互模拟器** | **强烈推荐** PhET「Buoyancy」+「Density」 |
| **阅读材料 / 书籍** | 《这就是物理》力与流体分册；《Feel the Force》 |
| **动手实验** | 1. 把橡皮泥捏成团沉入水中，再捏成小船形状让它浮起来<br>2. 观察不同形状对浮沉的影响<br>材料：橡皮泥、透明水盆、清水 |
| **直觉量化点** | 排开的水越多，浮力越大；形状决定能否浮起来 |
| **留下的钩子** | 压强是什么？为什么同样的力，踩在钉子上和踩在地板上感觉完全不一样？ |
| **知识地图节点** | 相互作用与场 · 第8次回旋 |
