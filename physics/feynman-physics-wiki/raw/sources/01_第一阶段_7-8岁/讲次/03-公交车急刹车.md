# 第3讲：公交车急刹车时人为什么往前倾？

| 项目 | 内容 |
|------|------|
| **课程标题** | 公交车急刹车时人为什么往前倾？ |
| **对应主线** | 运动与时空 |
| **核心问题** | 是谁推了你一把？为什么身体会往前冲？ |
| **自制 Notebook 视频** | 15–18分钟。用费曼口吻把“惯性”再加深一层，加入速度变化快慢的直觉。 |
| **外部视频参考** | 1. PhET 官方演示视频<br>2. 学而思/洋葱学园惯性相关动画 |
| **交互模拟器** | PhET「Forces and Motion: Basics」 |
| **阅读材料 / 书籍** | 《这就是物理》力与运动分册；《Feel the Force》相关页 |
| **动手实验** | 1. 坐在滑板车上突然被拦住，感受前倾<br>2. 光滑桌面放书，快速抽走下面的纸<br>材料：滑板车、书、光滑纸 |
| **直觉量化点** | 刹车越急（速度变化越快），前倾感觉越明显 |
| **留下的钩子** | 如果我们一直转圈，会觉得自己没动、世界在转吗？ |
| **知识地图节点** | 运动与时空 · 第3次回旋 |
