# 第14讲：热不是一种“热物质”

| 项目 | 内容 |
|------|------|
| **课程标题** | 热不是一种“热物质” |
| **对应主线** | 能量与账本 + 物质的微观建筑 |
| **核心问题** | 热到底是什么？是一种会流动的“热物质”吗？还是别的东西？ |
| **自制 Notebook 视频** | 16–20分钟。用费曼口吻复归能量守恒，推翻“热质说”，引出分子运动。 |
| **外部视频参考** | 1. Feynman《Fun to Imagine》——Heat is just jiggling atoms<br>2. 博雅小学堂「热」相关片段 |
| **交互模拟器** | PhET「Energy Forms and Changes」（可看到热能与其他能量的转化） |
| **阅读材料 / 书籍** | 《费曼讲物理：入门》能量守恒章节；《能量无处不在》 |
| **动手实验** | 1. 用手搓热，感受“做功生热”<br>2. 对比热水与冷水，思考“热”去哪里了<br>材料：双手即可 |
| **直觉量化点** | 摩擦、撞击都能生热——热与运动有关 |
| **留下的钩子** | 为什么墨水会在水里自己散开？分子真的在跳舞吗？ |
| **知识地图节点** | 能量与账本 · 第1次回旋；物质微观建筑 · 第1次回旋 |
