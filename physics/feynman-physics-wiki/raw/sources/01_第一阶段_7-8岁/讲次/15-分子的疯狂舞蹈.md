# 第15讲：分子的疯狂舞蹈——为什么墨水会在水里散开？

| 项目 | 内容 |
|------|------|
| **课程标题** | 分子的疯狂舞蹈：为什么墨水会在水里散开？ |
| **对应主线** | 物质的微观建筑 |
| **核心问题** | 墨水为什么会自己慢慢散开？是谁在推它们？ |
| **自制 Notebook 视频** | 15–18分钟。用费曼口吻从扩散现象进入，建立“分子一直在动”的图像。 |
| **外部视频参考** | 1. PhET「Diffusion」官方演示<br>2. 显微镜下布朗运动视频 |
| **交互模拟器** | **强烈推荐** PhET「Diffusion」+「Gas Properties」 |
| **阅读材料 / 书籍** | 《费曼讲物理》原子运动章节；《这就是物理》物质分册 |
| **动手实验** | 1. 在清水中滴一滴墨水或食物色素，静静观察扩散<br>2. 对比热水与冷水中的扩散速度<br>材料：透明杯子、清水、墨水/色素 |
| **直觉量化点** | 温度越高，扩散越快——分子跳得更疯 |
| **留下的钩子** | 温度到底是什么？是平均激烈的程度吗？ |
| **知识地图节点** | 物质微观建筑 · 第2次回旋 |
