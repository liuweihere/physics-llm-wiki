# 第2讲：向上抛球，为什么它总落回手里？

| 项目 | 内容 |
|------|------|
| **课程标题** | 向上抛球，为什么它总落回手里？ |
| **对应主线** | 运动与时空 |
| **核心问题** | 在开动的火车里向上抛球，球会不会落在后面？ |
| **自制 Notebook 视频** | 15–20分钟。用费曼口吻解释惯性，对比静止与运动两种情况，强调“带着原来的速度”。 |
| **外部视频参考** | 1. Crunch Labs 相关惯性短片<br>2. 李永乐老师「惯性」讲解短视频 |
| **交互模拟器** | PhET「Projectile Motion」（可切换参照系观察） |
| **阅读材料 / 书籍** | 《费曼讲物理：入门》；《这就是物理》惯性相关章节 |
| **动手实验** | 1. 坐在缓慢移动的玩具车/滑板上向上抛小球<br>2. 站在地面上做同样动作对比<br>材料：小球、滑板或玩具车 |
| **直觉量化点** | 球和你一起“带着”向前的速度（惯性） |
| **留下的钩子** | 公交车急刹车时，人为什么会往前倾？ |
| **知识地图节点** | 运动与时空 · 第2次回旋 |
