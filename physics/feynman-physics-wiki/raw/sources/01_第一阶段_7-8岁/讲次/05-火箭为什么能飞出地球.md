# 第5讲：火箭为什么能飞出地球？

| 项目 | 内容 |
|------|------|
| **课程标题** | 火箭为什么能飞出地球？ |
| **对应主线** | 运动与时空 + 相互作用与场（交叉） |
| **核心问题** | 火箭不靠空气也能飞，它推什么？为什么能越飞越快？ |
| **自制 Notebook 视频** | 18–22分钟。复归你已讲过的火箭，加入“相对什么加速”和反冲。 |
| **外部视频参考** | 1. Crunch Labs 火箭/反冲实验<br>2. 博雅小学堂相关片段 |
| **交互模拟器** | PhET「Gravity and Orbits」；简易反冲模拟 |
| **阅读材料 / 书籍** | 《费曼讲物理》；《这就是物理》力与运动 |
| **动手实验** | 1. 气球放气向前飞<br>2. 坐在滑板上向后扔重物<br>材料：气球、滑板、重物 |
| **直觉量化点** | 扔得越重、越快，自己向前的速度越大 |
| **留下的钩子** | 如果地球突然停止转动，会发生什么可怕的事？ |
| **知识地图节点** | 运动与时空 · 第5次回旋 |
